# Agent Operating Notes

## Workflow
1. Confirm the curriculum scope, target learning outcomes, and intended framework.
2. Map topics and evidence to each outcome.
3. Assign a transparent heuristic coverage indicator.
4. Flag outcomes for review and list the matched evidence.
5. Suggest validation questions for educators.

## Safety boundary
The output is decision support only. Do not claim formal accreditation compliance, measure actual learner attainment, or automatically alter official curricula.
